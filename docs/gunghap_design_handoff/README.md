# 궁합지도("인연지도") 디자인 핸드오프 패키지

> 젠스파크 디자이너님께: 이 폴더 하나로 **궁합지도가 지금 어떤 기능으로, 어떤 화면
> 흐름으로, 어떤 디자인으로 되어 있는지** 전부 확인하실 수 있습니다. 새 디자인
> 시안을 만들어 주시면, 개발자가 기존 로직(API·결제·공유·엔진)은 그대로 둔 채
> 화면(UI)만 새 시안으로 교체 구현합니다.

## 🖼️ screens 폴더가 가장 중요합니다

`screens/` 폴더의 21장은 **실제 코드에 반영된 디자인**을 화면별로 캡처한 것입니다.
파일명 앞 숫자(01~21)가 **실제 사용자가 화면을 만나는 순서**입니다. 디자이너님은
이 순서대로 훑어보시면 궁합지도 서비스 전체를 처음부터 끝까지 체험하듯 이해하실
수 있습니다.

각 화면 이미지는 `390×844`(iPhone 기준 모바일 세로 화면) 캔버스 안에 실제 앱
UI를 그대로 담고 있습니다 — 상태바, 하단 네비게이션까지 포함된 "완성 화면"
이미지이니 그대로 디자인 참고 자료로 사용하시면 됩니다.

## 📄 GUNGHAP_CURRENT_STRUCTURE.md도 꼭 봐주세요

화면 그림만으로는 안 보이는 정보— **색상 코드, 좌표·궤도 계산 공식, 오행 관계
로직, API 연동 방식, 절대 바뀌면 안 되는 로직** 등은 같은 폴더의
`GUNGHAP_CURRENT_STRUCTURE.md` 문서에 정리되어 있습니다.

- 새 디자인을 만들 때 **별의 위치/궤도 간격을 다시 그리시더라도** 문서 §5(좌표·궤도
  규칙)의 공식과 맞아야 실제 코드에 그대로 이식할 수 있습니다.
- 오행별 색상(木/火/土/金/水)이나 점수 구간별 색상(85+/70+/55+/~54) 같은 "의미가
  있는 색"은 문서 §4(디자인 토큰)에 현재 적용된 값이 적혀 있으니, 참고해서 바꾸시면
  됩니다(완전히 새 색상 팔레트로 바꾸셔도 되고, 다만 그 경우 어떤 점수대가 어떤
  색인지 매핑표만 함께 알려주시면 됩니다).

## 💬 디자이너님께 요청드리는 것

1. **21장의 화면을 참고하여 새로운 비주얼 디자인**으로 재구성해 주세요(레이아웃·
   컬러·타이포는 자유롭게 바꾸셔도 됩니다. 각 화면의 **기능적 구성요소**(버튼,
   입력 필드, 바텀시트 등)는 유지되어야 합니다 — 구조표 문서 §3에 화면별 구성요소가
   상세히 나와 있습니다).
2. 궁합지도 메인 화면(인연지도)의 핵심은 "별(사람)이 점수에 따라 다른 거리에
   위치하고, 빈 자리(미등록 관계)가 점선으로 보이는" 콘셉트입니다. 이 콘셉트 자체는
   유지해 주시되, 비주얼 스타일(색감, 질감, 별 모양 등)은 자유롭게 제안해 주세요.
3. 시안을 평면 이미지(PNG/Figma)로 주셔도 되고, 지금처럼 클릭 가능한 HTML
   프로토타입으로 주셔도 됩니다 — 둘 다 받으면 더 좋습니다.
4. 궁합지도와 비슷하게 생긴 **"귀인지도"는 완전히 다른 별개 서비스**입니다
   (디자인 의뢰 대상이 다름). 혹시 같이 작업하시는 경우 `GUINJI_CURRENT_STRUCTURE.md`
   문서를 별도로 참고해 주세요.
