# 마케팅쿠폰(복주머니 쿠폰) 관리자 매뉴얼

**작성 기준일**: 2026-10-22
**적용 범위**: 신통방통 관리자 사이트(admin_web) — 좌측 사이드바 "마케팅쿠폰" 메뉴
**문서 버전**: v1.0 (초안)

---

## 0. 이 기능이 하는 일 (한눈에 보기)

"마케팅쿠폰"은 QR코드/링크 형태의 쿠폰을 발행해서, 사용자가 등록하면 **복주머니(포인트)** 를 지급하는 기능입니다.

- 쿠폰은 **앱**에서도 **웹(브라우저)** 에서도 동일하게 등록·적립됩니다 (지갑이 플랫폼별로 분리되어 있지 않고 회원 1명당 1개이기 때문).
- 쿠폰을 담은 링크(`sintong.kr/coupon/{토큰}`)를 카카오톡 등으로 공유하면, 클릭 시 자동으로 앱(웹앱)으로 이동해 등록 화면이 뜹니다.
- 쿠폰은 **제휴업체**(오프라인 매장 등)에 "배정"해서 나눠주거나, 회원에게 직접 **푸시 알림**으로 선물할 수 있습니다.

### 전체 작업 흐름 요약

```
① 캠페인 만들기 (쿠폰 1종류 = 캠페인 1개)
   ↓
② (선택) AI로 쿠폰 디자인 만들기
   ↓
③ 캠페인 활성화 → 실제 쿠폰(개별 번호) 발행
   ↓
④-A 제휴업체에 배정 → 업체가 오프라인에서 배포       ┐
④-B 회원에게 직접 푸시로 선물                         ├─ 둘 중 하나 또는 둘 다
   ↓
⑤ 고객이 QR/링크로 쿠폰 등록 → 복주머니 자동 지급
   ↓
⑥ 사용 내역 / 통계 / 감사 로그로 관리·확인
```

## 1. 메뉴 구조

관리자 사이트 로그인 후 좌측 사이드바 **"마케팅쿠폰"** 클릭 → 상단에 7개 탭이 나타납니다.

| 번호 | 탭 이름 | URL | 용도 |
|---|---|---|---|
| ① | 쿠폰 만들기 / 발행 관리 | `/bokju-coupons/campaigns` | 캠페인 생성, 발행, 업체 배정, 디자인 편집 (가장 핵심) |
| ② | AI 쿠폰 디자인 | `/bokju-coupons/design-templates` | AI로 쿠폰 배경 이미지 생성 + 재사용 템플릿 관리 |
| ③ | 제휴업체 관리 | `/bokju-coupons/partners` | 제휴업체 등록 + 업체 전용 로그인 계정 발급 |
| ④ | 회원 푸시 발송 | `/bokju-coupons/push` | 쿠폰 이벤트를 회원에게 푸시로 알리거나 선물 |
| ⑤ | 쿠폰 사용 내역 | `/bokju-coupons/usage` | 누가 언제 등록(성공/실패)했는지 전체 로그 |
| ⑥ | 쿠폰 통계 | `/bokju-coupons/stats` | 캠페인별·업체별 발행/등록 수치 |
| ⑦ | 감사 로그 | `/bokju-coupons/audit-logs` | 관리자가 한 조작(발행/배정/삭제 등) 이력 |

접근 권한(RBAC): `super_admin`·`operator`는 전체 가능, `cs`는 조회만 가능, `content_manager`는 조회만 가능.

## 2. ① 쿠폰 만들기 / 발행 관리

### 2-1. 캠페인(쿠폰 종류) 생성

"+ 새 캠페인 만들기" 버튼을 누르면 입력 폼이 열립니다. 각 입력 항목(화면에 번호가 매겨져 있음, 폼 안의 ❓ 도움말 아이콘을 눌러도 같은 설명이 나옵니다):

| 항목 | 설명 |
|---|---|
| **1. 쿠폰명** (필수) | 관리자/고객에게 보이는 캠페인 제목 |
| **2. 쿠폰 디자인** | 내장 템플릿 4종(전통 복주머니/고급 선물/카카오톡 스타일/미니멀) 중 선택, 또는 ②AI 쿠폰 디자인에서 만든 커스텀 템플릿 선택 |
| **3. 지급 복주머니** (필수) | 쿠폰 1장 등록 시 지급할 복주머니 개수 (기본 100개). ※ 일일 적립 총량 상한 정책은 2026-10 폐지되어 설정값 그대로 전액 지급됨 |
| **5. 쿠폰 유형** | `INDIVIDUAL`(개별 — 쿠폰마다 고유 QR/번호, 1장=1회용) / `SHARED`(공용 — 하나의 QR을 여러 명이 공유, 아래 "공용 총 사용 한도"로 전체 사용량 제한) |
| **6. 사용 대상** | `ALL`(전체 회원) / `NEW`(신규 가입 7일 이내만) / `EXISTING`(기존 회원만) |
| **9. 1인당 발급 가능 수량** | 한 사람이 이 캠페인에서 몇 번까지 등록 가능한지 (기본 1회) |
| **총 발행 수량** | 이 캠페인에서 만들 쿠폰의 총 개수 상한. "무제한" 체크 가능(기본은 1,000장 한정) |
| **7. 사용 시작일** (필수) | 이 날짜 이전에는 등록 불가 |
| **8. 사용 만료일** (필수) | 이 날짜 이후에는 등록 불가(만료 처리) |
| **11. 배포 방식** | `DIRECT`(관리자가 직접 전달) / `PARTNER`(제휴업체 배정) / `GIFT`(회원 개별 선물용) |
| **10. 쿠폰 안내 문구** | 쿠폰 이미지에 들어가는 안내 텍스트 |
| **12. 모바일 쿠폰 미리보기** | 위 입력값을 반영한 실제 쿠폰 이미지를 실시간으로 미리 확인(디자인·번호·QR 포함) |

입력 후 저장하면 캠페인이 **DRAFT(초안)** 상태로 생성되고, 캠페인 상세 화면으로 이동합니다.

### 2-2. 캠페인 상세 화면

캠페인 목록에서 캠페인을 클릭하면 들어가는 화면. 아래 섹션들로 구성됩니다.

#### (1) 상태 전환
- DRAFT(초안) → **ACTIVE(활성화)**: "활성화" 버튼을 눌러야 실제로 쿠폰 발행/등록이 가능해집니다.
- ACTIVE 상태에서 "일시중지(PAUSED)" / "중지" 가능.

#### (2) 발행 쿠폰 관리 — 발행 현황판
5가지 숫자를 한눈에 보여줍니다:
- **총 발행 한도**: 이 캠페인에서 만들 수 있는 최대 쿠폰 수
- **발급 완료**: 지금까지 실제로 만든(issue) 쿠폰 수
- **사용 완료**: 고객이 등록(redeem)까지 완료한 수
- **발급 후 미사용**: 만들었지만 아직 등록 안 된 쿠폰 수
- **추가 발급 가능**: 총 한도 − 발급 완료 (이 수만큼 더 만들 수 있음)

"발행 수량" 입력란에 숫자를 넣고 "발행" 버튼을 누르면 그 수만큼 개별 쿠폰(고유 번호+QR)이 한 번에 생성됩니다. 총 발행 한도를 넘기려 하면 서버가 차단합니다.

#### (3) 신규 디자인으로 전환 / 쿠폰 디자인 스튜디오 열기
- 레거시(구버전) 디자인으로 만들어진 캠페인은 "신규 디자인으로 전환" 버튼으로 새 디자인 편집기를 쓸 수 있게 전환 가능.
- "쿠폰 디자인 스튜디오 열기" 링크 → 3번(아래) 디자인 스튜디오로 이동.

#### (4) 이미지 생성 관리
발행된 쿠폰 각각의 모바일 이미지(QR+디자인 합성 PNG)를 만드는 백그라운드 작업 현황. "전체 쿠폰 이미지 일괄 생성" 버튼으로 한 번에 생성 요청 가능. 실패한 작업은 재시도 가능.

#### (5) 쿠폰 배정 및 전달 (제휴업체용)
- "업체 선택" 드롭다운 + "수량" 입력 → 발급 완료되었지만 아직 배정 안 된 쿠폰 중 일부를 특정 제휴업체에 배정.
- 배정 후 "전달 완료" 처리하면 업체 쪽 화면(③ 제휴업체 관리에서 만든 로그인 계정)에서 해당 수량을 확인할 수 있게 됩니다.

#### (6) 회수 쿠폰 재배정
업체에 배정했다가 "미등록 회수"(배포 안 하고 되돌려받은 쿠폰) 처리된 것을 다른 업체에 다시 배정할 수 있는 섹션.

#### (7) 공유 섹션 (카카오톡 링크 공유)
발행된 개별 쿠폰의 등록 링크(`sintong.kr/coupon/{token}`)를 "링크 복사" 하거나 "카카오톡 공유" 버튼으로 바로 공유할 수 있습니다.
- ⚠️ 이미 **등록(REDEEMED)된 쿠폰은 삭제할 수 없습니다** (적립 기록과 연결된 금전적 사실이라 보호됨).

## 3. ② AI 쿠폰 디자인

"AI 쿠폰 디자인" 탭은 **쿠폰 이미지 자체를 꾸미는 화면**이며, 실제 발행/등록/적립 기능과는 완전히 분리되어 있습니다(여기서 QR코드나 쿠폰번호를 이미지에서 숨겨도 실제 서버 검증·적립 기능은 항상 그대로 작동).

3단계 패널 구성:
1. **AI 배경 생성**: 원하는 분위기를 문구로 입력(예: "빨간색과 금색의 고급스러운 전통 쿠폰")하면 AI가 배경 이미지를 생성
2. **표시 항목 선택**: 쿠폰 이미지에 보여줄 정보 11개 항목(쿠폰명/금액/QR/번호/만료일 등)을 체크박스로 켜고 끔
3. **실시간 미리보기 + 템플릿 저장**: 만든 조합을 "템플릿"으로 저장 → ①의 캠페인 생성 화면에서 선택 가능. 템플릿은 복사/보관(archive)/기본 지정/삭제 가능.

## 4. ③ 제휴업체 관리

### 4-1. 업체 등록
"+ 새 제휴업체 등록" → 업체명(필수), 담당자명, 연락처 입력 후 저장.

### 4-2. 로그인 계정 발급
등록된 업체 목록에서 "계정 발급" → 로그인ID + 비밀번호(8자 이상) 입력해 발급. 이 계정으로 업체 담당자가 별도의 **제휴업체 전용 포털**(`sintong.kr/partner/bokju-coupons/login`)에 로그인합니다.

### 4-3. 제휴업체가 보는 화면 (참고)
업체 로그인 후 보이는 "내가 받은 쿠폰" 화면에서 할 수 있는 일:
- 배정받은 쿠폰 목록과 수량 확인
- **"배정 확인(실물 수령)"** 버튼으로 수령 확인 처리
- 실제 고객에게 배포한 수량을 **"보고"** (날짜/수량/방법/메모 입력)
- 쿠폰 QR 이미지 **다운로드**
- 화면에 표시되는 4가지 숫자: 배정 수량 / 내가 보고한 수량 / 실제 등록(적립) 확인 수량 / 배정 확인 여부
- ⚠️ "업체가 보고한 수량"과 "실제 시스템에 등록(적립)된 수량"은 서로 다른 값이며 절대 합산해서는 안 됩니다(⑥ 통계 탭 참고).

## 5. ④ 회원 푸시 발송

ACTIVE 또는 PAUSED 상태인 캠페인을 골라 두 가지 방식 중 하나로 발송합니다.

| 방식 | 대상 | 동작 |
|---|---|---|
| **전체 이벤트 안내 (BROADCAST)** | 조건(전체/신규/기존)에 맞는 모든 회원 | 단순 알림만 발송. 쿠폰은 회원이 직접 등록해야 함 |
| **개별 선물 (INDIVIDUAL)** | 관리자가 직접 검색해서 선택한 특정 회원(들) | 쿠폰을 해당 회원에게 **먼저 배정**한 뒤 알림 발송. 발송이 실패해도 배정 자체는 유지됨 |

발송 이력 표에서 캠페인/방식/대상/제목/상태(COMPLETED·PARTIAL·FAILED)/성공·실패 건수/생성일시를 확인할 수 있습니다.

## 6. ⑤ 쿠폰 사용 내역

쿠폰 등록(QR/링크 클릭 후 등록 시도) **전체**를 기록하는 조회 전용 화면입니다. 성공만 보여주는 게 아니라 아래 6가지 결과 전부를 보여줍니다.

| 결과 | 의미 |
|---|---|
| 성공(등록·적립) | 정상적으로 복주머니 지급 완료 |
| 중복 차단 | 이미 등록된 쿠폰을 재시도 |
| 기간 만료 | 사용 만료일이 지난 쿠폰 |
| 중지/회수됨 | 관리자가 중지시킨 쿠폰 |
| 대상 아님 | 사용 대상 조건(신규/기존 등)에 안 맞는 회원이 시도 |
| 유효하지 않음 | 존재하지 않는 토큰 등 |

캠페인/결과 유형으로 필터링 가능, 30건씩 페이지 이동.

## 7. ⑥ 쿠폰 통계

캠페인별, 제휴업체별 집계를 보여주는 화면.

- **요약 카드 4개**: 총 캠페인 수 / 총 발행 수 / 총 배정 수 / 총 등록 수
- **캠페인별 테이블**: 발행/배정/등록 수, 전환율(%)
- **제휴업체별 테이블**: 배정 수량 / 업체 자체 보고 수량 / 실제 등록(적립) 수량, 등록률(%)

> ⚠️ **중요**: "업체 자체 보고(reportedQty)"는 업체가 수기로 입력한 값이고, "실제 등록(redeemedQty)"은 시스템이 QR 스캔으로 실제 확인한 값입니다. 두 숫자는 출처가 다르므로 **절대 더해서 하나의 숫자로 쓰면 안 됩니다.**

## 8. ⑦ 감사 로그

관리자가 수행한 주요 조작 행위를 최근 200건까지 기록합니다.

| 행위 코드 | 의미 |
|---|---|
| ISSUE | 쿠폰 발행 |
| STATUS_CHANGE | 캠페인 상태 변경(활성화/중지 등) |
| ALLOCATE | 제휴업체에 배정 |
| DELIVER | 전달(발송) 완료 처리 |
| RECALL | 미등록 쿠폰 회수 |
| REVOKE | 쿠폰 중지 |
| IMAGE_GENERATE_START | 이미지 생성 시작 |
| DELETE / BULK_DELETE | 쿠폰 삭제 / 일괄 삭제 |

일시, 행위, 대상, 내용, 실행자(관리자 ID)를 확인할 수 있습니다.

## 9. 자주 묻는 질문 (FAQ)

**Q1. 앱 사용자와 웹(브라우저) 사용자가 같은 쿠폰을 등록하면 복주머니가 각각 따로 쌓이나요?**
A. 아니요. 복주머니 지갑은 **회원 1명당 1개**이며 플랫폼 구분이 없습니다. 앱으로 등록하든 웹브라우저로 등록하든 동일한 지갑에 합산됩니다.

**Q2. 카카오톡으로 받은 쿠폰 링크를 클릭하면 어디로 연결되나요?**
A. `sintong.kr/coupon/{토큰}` 링크는 카카오톡 미리보기(OG 이미지)용 페이지일 뿐이며, 실제 사람이 클릭하면 즉시 `sintong.kr/app/#/coupon/{토큰}` (Flutter 앱/웹앱)으로 자동 이동해서 등록 절차가 진행됩니다.

**Q3. 쿠폰을 잘못 발행했어요. 삭제할 수 있나요?**
A. 아직 등록되지 않은(REDEEMED 상태가 아닌) 쿠폰은 삭제 가능합니다. 이미 고객이 등록해 복주머니가 지급된 쿠폰은 삭제가 차단됩니다(금전 기록 보호).

**Q4. "총 발행 수량"과 "1인당 발급 가능 수량"의 차이는?**
A. 총 발행 수량은 이 캠페인 전체에서 만들 수 있는 쿠폰의 최대 개수이고, 1인당 발급 가능 수량은 같은 회원 한 명이 몇 번까지 등록할 수 있는지를 제한하는 값입니다.

## 부록: 용어 정리

| 용어 | 의미 |
|---|---|
| 캠페인(Campaign) | 쿠폰의 "종류" 하나 — 예: "2026 설날 이벤트 쿠폰" |
| 쿠폰(Coupon) | 캠페인 안에서 발행된 개별 쿠폰 1장(고유 번호 + QR) |
| 발행(Issue) | 캠페인에서 실제 쿠폰(개별 번호)을 만드는 행위 |
| 배정(Allocate) | 발행된 쿠폰을 특정 제휴업체 몫으로 할당하는 행위 |
| 전달(Deliver) | 배정된 쿠폰을 실제로 업체에 넘겼다고 표시하는 행위 |
| 등록/적립(Redeem) | 최종 고객이 쿠폰을 사용해 복주머니를 지급받는 행위 |
| 회수(Recall) | 배정했으나 배포되지 않은 쿠폰을 관리자가 되돌려받는 행위 |
